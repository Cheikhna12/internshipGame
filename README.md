# Internship Quest - Fighting Game

Jeu de combat 2D en Java sur le thème de la recherche d'alternance. Développé avec LibGDX et Maven.

## Démarrage rapide

### Prérequis
- Java 17 ou supérieur
- Maven 3.6+

### Installation

```bash
# Cloner le projet
git clone <votre-repo>
cd java_2D

# Compiler le projet
mvn clean x²

# Lancer le jeu
mvn exec:java
```
